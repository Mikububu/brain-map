# raw/

Source materials for ingestion (PDFs, articles, exports, symlinks). **This folder is local-only**; nothing inside (except this README) is committed to the repo.

This sub-wiki is the **template** for the Karpathy pattern. Drop a source file here, then ask Claude to ingest it. The wiki reads from this folder; Claude writes only to `../wiki/`.

Convention: never edit anything in `raw/` once it's been ingested. Treat sources as immutable inputs.
