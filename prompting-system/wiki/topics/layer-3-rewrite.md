# Layer 3 Rewrite

The literary transformation step. The fidelity checkpoint. Where System + Voice produces a draft, Layer 3 rewrites it as literature in the target language without losing the system's specificity.

## What it does

Layer 3 receives:

- The original system-narrative (English, generated from System + Voice layers)
- A literary voice anchor matched to the target language
- A preservation rule: the system's *core mechanism* (obsession, compulsion, shame, erotic truth, neecha, klipoth, shadow, signature / not-self) must survive transformation

It produces a polished prose reading in the target language that reads like literature, not translation.

## Native generation, not translation

> "Layer 3 is written in the language the user selects. It isn't translated."

The English text generated by System + Voice is **not** a source for translation; it is a *reference structure*. The Layer 3 model writes the actual reading natively in the user-selected language, anchored to a culturally native literary voice. The English version is scaffolding the reader never sees.

This is why **the LLM choice itself varies per language** (see [[topics/per-language-llms]]). Translation-quality models are not the same as native-generation-quality models. The model that handles Japanese well is not necessarily the model that handles Hindi well, and the [[vedic]] vocabulary problem (Sanskrit-rooted terms in non-Romance languages) makes this difference operationally visible.

## The fidelity rule

If the system's core mechanism *disappears* during rewrite, Layer 3 has failed.

The user discovered this the hard way (`960af36c`, "Stop rewrite layer from flattening system identity"). The rewrite was making Vedic sound like Western, Kabbalah sound like Gene Keys. The fix: standardised preservation rules across all 11 languages.

## The ghost-writer reframe

**2026-03-21** (`cf2e3d3b`). Layer 3 reframed as a ghost-writer task: *"Write the masterpiece you never finished."* Personas invoked: Houllebecq, Mishima, García Márquez, Elfriede Jelinek.

This was the move that made Layer 3 stop sounding like edited model output and start sounding like literature.

## The compression

**2026-03-29** (`3eb84ab3`). Layer 3 compressed from 72 lines to 23 with a psychosexual preamble. Less instruction, more trust.

## Native voice anchors per language

See [[topics/language-anchoring]]. The 11 languages each pair with a culturally native literary voice (Osho for Hindi, Pelevin for Russian, Yu Hua for Mandarin) rather than imposing English literary taste.

## How each app uses Layer 3

- [[apps/1-in-a-billion]]: canonical. 11 languages, native voice anchors.
- [[apps/unhinged]]: diverges in the rewrite contract (Henry Miller anchor, chaos-comedy override).
- [[apps/past-life-contracts]]: minimised. The chart is computed before the LLM writes; Layer 3 is an optional polish.
