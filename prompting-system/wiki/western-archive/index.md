# Western Archive

Raw source material. No interpretation. The actual code and prompt content from git, verbatim.

**Note**: Western is structurally different from the other four voices. It does NOT have its own `western-individual.md` / `western-synastry.md` / `western-individual-incarnation.md` files. Western lives mostly in **TypeScript** (`backend/src/prompts/systems/western.ts`) and inherits its narrator definition from `voice-architecture-all-systems.md`. Western readings flow through the shared **Layer 3 rewrite** (`narrative-rewrite-en.md`).

For the synthesised view, see [[voices/western]]. This archive is the raw material.
