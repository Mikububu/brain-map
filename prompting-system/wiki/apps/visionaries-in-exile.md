# Visionaries in Exile

A 1995-1996 Macromedia Director CD-ROM. The builder's earliest published interactive art project. Currently being **1:1 restored** as a web project at `Mikububu/visionaries-in-exile` (GitHub repo created 2026-04-22).

## Out of scope for the prompting brain-map

Visionaries in Exile predates the four-app suite by ~30 years. It is not part of the prompting / voice / matching research thread documented elsewhere in this wiki. It's noted here as **builder context**: a long arc of art-software work that the four current apps sit downstream of.

## What it was (and is being restored as)

- Original: 1995-1996 Macromedia Director CD-ROM titled *Visionaries in Exile / Architects in Exile*
- Restoration: 1:1 web port using a ProjectorRays-based pipeline (the `rebuild/` subfolder of the repo contains the ProjectorRays decoder)
- Local repo path: `~/Desktop/my Iphone apps/Visionaries in Exile /rebuild/`

## Connection to the prompting work

None directly. The interest in *consciousness*, *interior states*, and *literature-as-software* that runs through [[apps/1-in-a-billion]], [[apps/unhinged]], [[apps/past-life-contracts]], and [[apps/families-app]] is older than the prompts. Visionaries was the first version of that interest, in 1995.
